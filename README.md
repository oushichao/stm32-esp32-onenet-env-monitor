# SmartEnv-IoT · 智能环境监测物联网系统

## ✨ 核心功能

- 🌡️ **多传感器采集**：温度、湿度、光照强度实时采集
- 📺 **本地显示**：OLED 实时显示传感器数据与联网状态
- 🔌 **继电器控制**：支持本地按键与云端远程双重控制
- 📡 **可靠通信**：自定义串口协议帧，带 CRC 校验与状态机解析
- ☁️ **云端联动**：MQTT 协议接入 OneNET 平台，支持数据上报与命令下发
- ⚙️ **阈值管理**：云端可动态下发温湿度阈值，超限自动触发继电器
- 🔄 **断线重连**：WiFi / MQTT 断开后自动恢复，保障长期稳定运行
- 🧵 **多任务架构**：双 MCU 均基于 FreeRTOS 实现任务解耦

## 🏗️ 系统架构

```
                    ┌─────────────────────────┐
                    │     OneNET 云平台        │
                    │  （数据存储 / Web 监控） │
                    └───────────┬─────────────┘
                                │ MQTT over TCP
                                │
                    ┌───────────▼─────────────┐
                    │       ESP32-S3          │
                    │  · WiFi 连接             │
                    │  · MQTT 客户端           │
                    │  · 协议帧解析/组装        │
                    │  · FreeRTOS 多任务       │
                    └───────────┬─────────────┘
                                │ UART + 自定义协议帧
                                │
                    ┌───────────▼─────────────┐
                    │      STM32F103          │
                    │  · 传感器采集            │
                    │  · OLED 显示            │
                    │  · 继电器控制           │
                    │  · FreeRTOS 多任务      │
                    └──┬──────────────┬───────┘
                       │              │
              ┌────────▼───┐     ┌────▼──────┐
              │ 传感器模块  │     │ 继电器模块 │
              │ (温湿度等) │     │           │
              └────────────┘     └───────────┘
```

**设计思路**：STM32 专注实时采集与本地交互（响应快、外设丰富），
ESP32 专职网络通信（WiFi + 协议栈），职责分离提升系统稳定性。

## 🛠️ 技术栈

| 模块 | 技术选型 |
|------|---------|
| 采集端 MCU | STM32F103 + HAL 库 |
| 通信端 MCU | ESP32-S3 + ESP-IDF |
| 实时系统 | FreeRTOS（双端） |
| MCU 间通信 | UART + 自定义协议帧 |
| 网络协议 | WiFi / TCP / MQTT |
| 云平台 | OneNET |
| 显示 | SSD1306 OLED（I²C） |
| 开发工具 | Keil MDK / VSCode + ESP-IDF / Git |

### OneNET 平台配置

1. 登录 [OneNET](https://open.iot.10086.cn/) 注册账号
2. 创建产品 → 添加设备 → 获取设备 ID 与 Token
3. 将设备信息填入 ESP32 的 `menuconfig` 对应项
4. 云端创建数据流模板（temp / humi / light / relay 等）
